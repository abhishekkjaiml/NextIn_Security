# 📖 Overview

NextIn Security is a frontend web development project built using **HTML5** and **CSS3**. It is a security-themed website created to practice webpage structure, layout design, and styling techniques.

The project demonstrates how to build a professional-looking multi-page website using only HTML and CSS without relying on JavaScript or backend technologies.

# 🚀 Getting Started

## Prerequisites

- Web Browser
- Visual Studio Code (Recommended)
- Live Server Extension (Optional)

---

## Clone Repository

```bash
git clone https://github.com/abhishekkjaiml/NextIn_Security.git
```

---

## Navigate to Project

```bash
cd NextIn_Security
```

---

## Run the Project

Open **index.html** directly in your browser.

Or use the **Live Server** extension in Visual Studio Code.
